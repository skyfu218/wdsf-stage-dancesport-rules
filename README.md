# WDSF 舞臺運動舞蹈規則查詢

依據《WDSF Presidium Operating Policy on Rules for the Stage DanceSport Discipline》整理的繁體中文互動查詢工具。

## 功能

- 依舞種、競賽形式、年齡組與規則主題交叉篩選
- 支援關鍵字搜尋與一鍵重設
- 區分「手冊規定」「臺灣執行提醒」「原文待確認」
- 顯示對應 WDSF 條號
- 支援手機、平板、電腦與列印
- 單一靜態網頁，可離線使用

## 舞種範圍

- Jazz Dance（爵士舞）
- Contemporary Dance（當代舞）
- ShowDance Stage（舞臺展演舞）
- Tap Dance（踢踏舞）

## 使用限制

本系統是中文摘要查詢工具，不取代 WDSF 正式英文規則。辦理報名、執法、申訴或代表隊選拔前，仍應核對當年度 WDSF 規則與賽事公告。
